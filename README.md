# After the Demark

Website for After the Demark: home network assessments, whole-home Wi-Fi, Ethernet wiring and smart home installs in Elmira, Corning, Horseheads and the Southern Tier of New York.

- `index.html`: main page
- `guide.html`: free "5 signs" guide
- `styles.css`, `script.js`: shared styles and the contact form
- `media/`: promo video, poster and link-preview image
- `video-src/`: code that renders the promo video (see its README)

Live at https://patinthehat007.github.io/after-the-demark/ once GitHub Pages is enabled.
